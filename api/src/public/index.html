API de Cartas do Yu-Gi-Oh!

Uma API local de alto desempenho em Node.js com tradução de tipos, atributos e vinculo com imagens locais em alta definição em português brasileiro.

Explore as Cartas

Pesquise por qualquer carta para carregar suas informações e imagem em alta definição no painel lateral.

Endpoints da API

GET /api/cartas

Retorna a lista de todas as cartas mapeadas com suporte a paginação e filtros de query parameters.

Query Params: nome, tipo_carta, tipo, atributo, nivel, page, limit
GET /api/cartas/:id

Retorna os detalhes completos em português de uma única carta especificada pelo seu ID numérico.

GET /api/cartas/nome/:nome

Retorna os detalhes de uma carta buscando pelo seu nome (em português ou inglês). Faz busca exata primeiro e depois parcial.

STATIC /imagens/:categoria/:arquivo.png

Rota estática que serve os arquivos locais das cartas em alta resolução diretamente do disco.
